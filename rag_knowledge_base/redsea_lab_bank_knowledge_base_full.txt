1. REFER-A-FRIEND PROGRAM OVERVIEW
--------------------------------------------------------------------------------

1.1 Program Incentive
- Referrer Reward: $50 cash bonus deposited directly into checking account per qualified referral.
- Referee (Friend) Reward: $50 welcome bonus upon opening a new account and making an initial deposit of $100+.
- Annual Maximum Bonus: Up to $500 per customer per calendar year (10 successful referrals).

1.2 How It Works
1. Log in to the Red Sea Lab Bank Portal and navigate to the "Refer a Friend" tab.
2. Copy your unique referral URL or enter your friend's email address in the invitation form.
3. Your friend receives an invitation link formatted as:
   https://redsealabbank.apps.openshift.com/invite/<YOUR_REFERRAL_CODE>
4. Once your friend opens an account and deposits $100 within 30 days, both $50 bonuses are automatically paid out.

--------------------------------------------------------------------------------
1. MICROSERVICES ARCHITECTURE & ENDPOINTS
--------------------------------------------------------------------------------

1.1 Microservices Mapping
- Main Web Frontend (Path: /)
  * Container Image: docker.io/gregcoward/myarcadia:latest
  * Technology: Unprivileged NGINX (Alpine base), HTML5, CSS3, ES6 JavaScript.
  * Role: Serves banking dashboard UI, authentication modal, and Flowise Chatbot snippet.

- Backend Service (Path: /files)
  * Role: Manages customer database records, transaction ledgers, and statement file downloads.

- Money Transfer API (Path: /api)
  * Role: Handles wire transfers, account balance queries, and instant funds transfers.

- Referral Microservice (Path: /app3)
  * Role: Manages invite links, referral code generation, and reward tracking.

1.2 OpenShift & Container Security Specifications
- Base Image: nginxinc/nginx-unprivileged:alpine
- Container Port: 8080 (Non-root, unprivileged port)
- Target CPU / Memory Architecture: linux/amd64
- Security Context Constraints (SCC): Restricted / Restricted-v2 compliant.
- Health Probes:
  * Liveness Probe: HTTP GET /healthz on port 8080 (initialDelay: 5s, period: 10s)
  * Readiness Probe: HTTP GET /healthz on port 8080 (initialDelay: 2s, period: 5s)
